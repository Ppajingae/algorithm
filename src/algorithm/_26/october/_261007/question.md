# 이중우선순위큐

## 문제 설명

이중 우선순위 큐는 다음 연산을 수행할 수 있는 자료구조입니다.

| 명령어 | 동작 |
|---|---|
| `I 숫자` | 큐에 주어진 숫자를 삽입합니다. |
| `D 1` | 큐에서 최댓값을 삭제합니다. |
| `D -1` | 큐에서 최솟값을 삭제합니다. |

문자열 배열 `operations`가 주어질 때 모든 연산을 순서대로 처리합니다.

모든 연산을 처리한 후:

- 큐가 비어있으면 `[0, 0]`
- 큐가 비어있지 않으면 `[최댓값, 최솟값]`

을 반환하도록 `solution` 함수를 완성하세요.

---

## 제한사항

```text
1 ≤ operations.length ≤ 1,000,000
```

`operations`의 각 원소는 다음 형식입니다.

```text
"명령어 데이터"
```

예:

```text
"I 16"
"I -5643"
"D 1"
"D -1"
```

추가 조건:

- 최댓값 또는 최솟값이 여러 개 존재하는 경우 **하나만 삭제**합니다.
- 빈 큐에서 삭제 명령이 들어오면 해당 명령은 **무시**합니다.

---

## 입출력 예

### 예제 1

```java
String[] operations = {
    "I 16",
    "I -5643",
    "D -1",
    "D 1",
    "D 1",
    "I 123",
    "D -1"
};

int[] expected = {0, 0};
```

결과:

```java
{0, 0}
```

### 예제 2

```java
String[] operations = {
    "I -45",
    "I 653",
    "D 1",
    "I -642",
    "I 45",
    "I 97",
    "D 1",
    "D -1",
    "I 333"
};

int[] expected = {333, -45};
```

결과:

```java
{333, -45}
```

# 예제 1 동작

초기 상태:

```text
[]
```

### `"I 16"`

```text
[16]
```

### `"I -5643"`

```text
[16, -5643]
```

### `"D -1"`

최솟값 `-5643` 삭제:

```text
[16]
```

### `"D 1"`

최댓값 `16` 삭제:

```text
[]
```

### `"D 1"`

현재 큐가 비어 있으므로 무시:

```text
[]
```

### `"I 123"`

```text
[123]
```

### `"D -1"`

최솟값 `123` 삭제:

```text
[]
```

최종적으로 비어 있으므로:

```java
return new int[]{0, 0};
```

# 예제 2 동작

```text
I -45
I 653

→ [-45, 653]
```

최댓값 삭제:

```text
D 1

→ [-45]
```

이후:

```text
I -642
I 45
I 97

→ [-642, -45, 45, 97]
```

최댓값 삭제:

```text
D 1

→ [-642, -45, 45]
```

최솟값 삭제:

```text
D -1

→ [-45, 45]
```

`333` 삽입:

```text
I 333

→ [-45, 45, 333]
```

따라서:

```java
return new int[]{333, -45};
```

# 이번 문제에서 먼저 볼 부분

입력 크기가 꽤 큽니다.

```text
operations.length ≤ 1,000,000
```

따라서 매 명령마다 전체 데이터를 순회해서:

```text
최댓값 찾기
최솟값 찾기
삭제하기
```

를 반복하는 구조라면 연산량을 한번 계산해볼 필요가 있습니다.

최악의 경우 대략:

```text
1,000,000 × 현재 데이터 개수
```

형태까지 커질 수 있습니다.

# 생각해볼 질문

이 문제에서 필요한 연산은 사실 세 가지입니다.

```text
1. 값 삽입
2. 현재 최댓값 하나 삭제
3. 현재 최솟값 하나 삭제
```

그리고 마지막에는:

```text
현재 최댓값
현재 최솟값
```

도 알아야 합니다.

따라서 구현하기 전에 먼저 생각해볼 건:

```text
어떤 자료구조를 사용해야
삽입 / 최솟값 조회·삭제 / 최댓값 조회·삭제
를 반복적으로 빠르게 처리할 수 있을까?
```

입니다.

`operations`가 최대 **100만 개**라는 조건도 같이 보고 자료구조부터 한번 정해보면 됩니다.
