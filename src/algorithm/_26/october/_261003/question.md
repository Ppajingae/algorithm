# 크기가 작은 부분문자열

## 문제 설명

숫자로 이루어진 문자열 `t`와 `p`가 주어집니다.

`t`에서 `p`와 **길이가 같은 부분문자열**을 모두 확인했을 때, 해당 부분문자열이 나타내는 수가 `p`가 나타내는 수보다 **작거나 같은 경우의 개수**를 구하세요.

예를 들어:

```java
String t = "3141592";
String p = "271";
```

`p`의 길이는 `3`이므로 `t`에서 길이가 `3`인 부분문자열을 확인합니다.

```text
314
141
415
159
592
```

이 중:

```text
141 <= 271
159 <= 271
```

이므로 결과는:

```java
2
```

입니다.

---

## 제한사항

```text
1 ≤ p.length() ≤ 18

p.length() ≤ t.length() ≤ 10,000

t와 p는 숫자로만 이루어진 문자열입니다.

t와 p는 0으로 시작하지 않습니다.
```

주의할 점:

```text
p의 최대 길이 = 18
```

이므로 숫자로 변환할 경우 자료형의 범위를 생각해야 합니다.

또한 `t` 자체는 최대 길이가 `10,000`이므로 `t` 전체를 하나의 숫자로 변환하는 것은 불가능합니다.

---

## 입출력 예

| t | p | result |
|---|---|---:|
| `"3141592"` | `"271"` | `2` |
| `"500220839878"` | `"7"` | `8` |
| `"10203"` | `"15"` | `3` |

# 입출력 예 #1

```java
String t = "3141592";
String p = "271";
```

`p.length()`:

```text
3
```

따라서 길이 3씩 확인합니다.

```text
314 → 271보다 큼

141 → 271보다 작음   O

415 → 271보다 큼

159 → 271보다 작음   O

592 → 271보다 큼
```

따라서:

```java
return 2;
```

# 입출력 예 #2

```java
String t = "500220839878";
String p = "7";
```

`p`의 길이가 `1`이므로 한 글자씩 확인합니다.

```text
5 → O
0 → O
0 → O
2 → O
2 → O
0 → O
8 → X
3 → O
9 → X
8 → X
7 → O
8 → X
```

따라서:

```java
return 8;
```

# 입출력 예 #3

```java
String t = "10203";
String p = "15";
```

`p.length()`:

```text
2
```

길이 2의 부분문자열은:

```text
10
02
20
03
```

비교하면:

```text
10 <= 15 → O

02 <= 15 → O
02는 숫자로 보면 2

20 <= 15 → X

03 <= 15 → O
03은 숫자로 보면 3
```

따라서:

```java
return 3;
```

# 생각해볼 부분

이번 문제에서 먼저 정해야 할 것은 크게 두 가지입니다.

```text
1. t에서 길이가 p.length()인 부분문자열을
   어떻게 하나씩 가져올 것인가?

2. 가져온 부분문자열과 p의 크기를
   어떻게 비교할 것인가?
```

예를 들어:

```java
String t = "3141592";
String p = "271";
```

라면 필요한 구간은:

```text
index 0 ~ 2 → "314"
index 1 ~ 3 → "141"
index 2 ~ 4 → "415"
index 3 ~ 5 → "159"
index 4 ~ 6 → "592"
```

처럼 **시작 위치가 한 칸씩 이동**합니다.

---

## 입력 크기 체크

`t`의 최대 길이는:

```text
10,000
```

이고 `p`의 길이를 `M`이라고 하면 확인해야 하는 부분문자열의 개수는:

```text
t.length() - M + 1
```

입니다.

예를 들어:

```text
t.length() = 7
p.length() = 3

7 - 3 + 1
= 5개
```

실제로:

```text
314
141
415
159
592
```

5개입니다.

---

## 주의할 점

이번 문제에서는 특히 이 제한을 한번 보고 구현하는 게 좋습니다.

```text
p.length() ≤ 18
```

Java에서 숫자로 변환하려고 한다면:

```text
int로 충분한가?

long은 가능한가?
```

를 확인해볼 필요가 있습니다.

그리고:

```text
"02"
"03"
```

같은 부분문자열도 나올 수 있습니다.

숫자로 해석하면 각각:

```text
2
3
```

입니다.

## 목표

일단 알고리즘 종류는 신경 쓰지 않고:

```text
t를 한 번 순회하면서

p와 같은 길이의 부분문자열을 하나씩 확인하고

p 이하라면 answer++
```

정도의 구조부터 직접 만들어보면 됩니다.
