# 가장 먼 노드

## 문제 설명

n개의 노드가 있는 그래프가 있습니다.

각 노드는 `1`부터 `n`까지 번호가 적혀있습니다.

`1번 노드`에서 가장 멀리 떨어진 노드의 개수를 구하려고 합니다.

가장 멀리 떨어진 노드란 **최단경로로 이동했을 때 간선의 개수가 가장 많은 노드**를 의미합니다.

노드의 개수 `n`, 간선에 대한 정보가 담긴 2차원 배열 `vertex`가 매개변수로 주어질 때,  
`1번 노드`로부터 가장 멀리 떨어진 노드가 몇 개인지를 `return`하도록 `solution` 메소드를 작성해주세요.

---

## 제한사항

- 노드의 개수 `n`은 `2 이상 20,000 이하`입니다.
- 간선은 **양방향**입니다.
- 간선은 총 `1개 이상 50,000개 이하`입니다.
- `vertex` 배열의 각 행 `[a, b]`는 `a번 노드`와 `b번 노드` 사이에 간선이 있다는 의미입니다.

---

## 입출력 예

| n | vertex | return |
|---|---|---:|
| 6 | `[[3,6],[4,3],[3,2],[1,3],[1,2],[2,4],[5,2]]` | 3 |

---

## Java 테스트 데이터

```java
int n = 6;

int[][] vertex = {
    {3, 6},
    {4, 3},
    {3, 2},
    {1, 3},
    {1, 2},
    {2, 4},
    {5, 2}
};

int expected = 3;
```

---

## 입출력 예 설명

주어진 간선은 다음과 같습니다.

```text
3 ↔ 6
4 ↔ 3
3 ↔ 2
1 ↔ 3
1 ↔ 2
2 ↔ 4
5 ↔ 2
```

`1번 노드`에서 출발했을 때 가장 멀리 떨어진 노드는:

```text
4번
5번
6번
```

총 `3개`입니다.

따라서:

```java
return 3;
```

---

## 핵심 요구사항

구해야 하는 것은 단순히 번호가 큰 노드나 물리적으로 멀어 보이는 노드가 아닙니다.

```text
1번 노드
    ↓
각 노드까지의 최단경로를 구했을 때
    ↓
사용되는 간선의 개수가 가장 큰 거리
    ↓
그 거리를 가진 노드가 몇 개인지 계산
```

---

## 입력 크기

```text
노드 최대: 20,000
간선 최대: 50,000
```

따라서 구현 전에 최대 입력에서 현재 접근 방법이 몇 번 정도 연산하게 될지도 같이 확인해볼 것.
