# 단속카메라

## 문제 설명

고속도로를 이동하는 모든 차량이 고속도로를 이용하면서 **단속용 카메라를 한 번 이상 만나도록** 카메라를 설치하려고 합니다.

고속도로를 이동하는 차량의 경로 `routes`가 매개변수로 주어질 때, 모든 차량이 한 번은 단속용 카메라를 만나도록 하기 위해 필요한 **최소 카메라 개수**를 `return`하도록 `solution` 메소드를 작성해주세요.

---

## 제한사항

- 차량의 대수는 `1대 이상 10,000대 이하`입니다.
- `routes[i][0]`은 `i번째 차량의 진입 지점`입니다.
- `routes[i][1]`은 `i번째 차량의 진출 지점`입니다.
- 차량의 진입/진출 지점에 카메라가 설치되어 있어도 해당 차량이 카메라를 만난 것으로 간주합니다.
- 차량의 진입/진출 지점은 `-30,000 이상 30,000 이하`입니다.

---

## 입출력 예

| routes | return |
|---|---:|
| `[[-20,-15], [-14,-5], [-18,-13], [-5,-3]]` | 2 |

---

## Java 테스트 데이터

```java
int[][] routes = {
    {-20, -15},
    {-14, -5},
    {-18, -13},
    {-5, -3}
};

int expected = 2;
```

---

## 입출력 예 설명

주어진 차량들의 이동 구간은 다음과 같습니다.

```text
1번 차량
-20 ---------------- -15

2번 차량
      -14 ---------------------- -5

3번 차량
  -18 ----------- -13

4번 차량
                            -5 -------- -3
```

`-15` 지점에 카메라를 설치하면:

```text
[-20, -15]
[-18, -13]
```

첫 번째 차량과 세 번째 차량이 카메라를 만나게 됩니다.

`-5` 지점에 카메라를 설치하면:

```text
[-14, -5]
[-5, -3]
```

두 번째 차량과 네 번째 차량이 카메라를 만나게 됩니다.

따라서 필요한 최소 카메라 개수는:

```java
2
```

입니다.

---

# 문제에서 구해야 하는 것

각 차량은 다음과 같은 **구간**을 가지고 있습니다.

```text
[진입 지점, 진출 지점]
```

카메라가 해당 구간 안에 하나라도 존재하면 그 차량은 단속됩니다.

즉:

```text
차량 A = [start, end]

start <= camera <= end
```

이면 해당 차량은 처리된 것입니다.

목표는:

```text
모든 차량의 구간에
최소 하나 이상의 카메라가 포함되도록 하면서

카메라 개수를 최소화
```

하는 것입니다.

---

# 입력 크기

차량은 최대:

```text
10,000대
```

입니다.

따라서 접근 방법을 생각할 때 현재 알고리즘의 최악 연산량도 같이 확인해봅니다.

예를 들어 모든 차량끼리 비교한다면:

```text
10,000 × 10,000
= 100,000,000
```

수준까지 커질 수 있습니다.

---

# 먼저 생각해볼 부분

정답 알고리즘을 바로 정하지 말고 다음 상황부터 생각해봅니다.

```text
차량 A
───────────────

차량 B
       ───────────────

차량 C
          ──────────
```

여러 차량의 이동 구간이 서로 겹친다면:

```text
카메라 1대로
여러 차량을 동시에 처리할 수 있다.
```

반대로:

```text
차량 A
───────

              차량 B
              ───────
```

처럼 구간이 완전히 떨어져 있다면 같은 카메라로 두 차량을 처리할 수 없습니다.

따라서 이번 문제에서 먼저 생각해볼 것은:

```text
1. 어떤 차량들을 카메라 하나로 묶어서 처리할 수 있을까?

2. 카메라를 어느 위치에 설치하면
   앞으로 등장할 다른 차량까지 최대한 같이 처리할 수 있을까?

3. 차량을 입력 순서 그대로 확인하는 것이 좋을까?
   아니면 특정 기준으로 정렬하면 판단이 쉬워질까?
```

일단 여기서부터 직접 접근해보기.
