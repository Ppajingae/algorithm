# 둘만의 암호

## 문제 설명

두 문자열 `s`, `skip`과 자연수 `index`가 주어집니다.

다음 규칙에 따라 `s`의 각 알파벳을 변환하여 새로운 문자열을 만들어야 합니다.

### 암호 규칙

1. 문자열 `s`의 각 알파벳을 `index`만큼 뒤의 알파벳으로 바꿉니다.
2. 이동하다가 `z`를 넘어가면 다시 `a`부터 시작합니다.
3. 이동 중 `skip`에 포함된 알파벳은 **이동 횟수에 포함하지 않고 건너뜁니다.**

---

## 예시

```java
String s = "aukks";
String skip = "wbqd";
int index = 5;

String expected = "happy";
```

첫 번째 문자:

```text
a
```

에서 `5`번 이동해야 합니다.

일반적으로는:

```text
b → c → d → e → f
```

이지만 `skip`은:

```text
w, b, q, d
```

입니다.

따라서 `b`, `d`는 세지 않습니다.

실제 이동은:

```text
a
↓
b  → skip
c  → 1
d  → skip
e  → 2
f  → 3
g  → 4
h  → 5
```

따라서:

```text
a → h
```

가 됩니다.

나머지 문자도 같은 규칙으로 변환하면:

```text
a → h
u → a
k → p
k → p
s → y
```

최종 결과:

```text
happy
```

---

# 제한사항

```text
5 ≤ s.length() ≤ 50

1 ≤ skip.length() ≤ 10

s와 skip은 알파벳 소문자로만 구성

skip에 포함된 알파벳은 s에 포함되지 않음

1 ≤ index ≤ 20
```

| s | skip | index | result |
|---|---|---:|---|
| `"aukks"` | `"wbqd"` | `5` | `"happy"` |

# 문제에서 주의할 부분

## 1. skip 문자는 이동 횟수에 포함되지 않는다

예를 들어:

```text
현재 문자 = a
skip = "bd"
index = 3
```

이라고 하면:

```text
b → skip
c → 1
d → skip
e → 2
f → 3
```

따라서:

```text
a → f
```

입니다.

단순히 `a + 3`을 한 다음 `skip`을 확인하는 방식과는 다릅니다.

---

## 2. z를 넘어가면 다시 a로 돌아간다

예를 들어:

```text
현재 문자 = y
index = 3
```

이라면 알파벳 이동 자체는:

```text
y → z → a → b
```

형태로 순환합니다.

여기에 `skip`까지 적용해야 합니다.

---

# 입력 크기 확인

최대:

```text
s.length() = 50
index = 20
skip.length() = 10
```

정도입니다.

따라서 각 문자를 직접 이동시키면서 확인하더라도 반복 횟수가 매우 작습니다.

예를 들어 각 문자마다 최대 몇십 번 정도 알파벳을 이동한다고 해도 전체 연산량은 충분히 작습니다.

이번 문제는 성능 최적화보다 **문제의 이동 규칙을 코드로 정확하게 옮기는 것**이 더 중요해 보입니다.

---

# 구현 전에 생각해볼 것

`s`의 각 문자를 하나씩 처리한다고 생각해봅시다.

```text
현재 문자
    ↓
다음 알파벳으로 이동
    ↓
z를 넘었는가?
    ↓
skip에 포함되어 있는가?
    ↓
아니라면 이동 횟수 +1
    ↓
index번 이동했는가?
```

특히 다음 두 가지를 분리해서 생각하면 좋습니다.

```text
알파벳을 실제로 한 칸 이동한 횟수

vs

skip을 제외하고 유효하게 이동한 횟수
```

둘은 서로 다를 수 있습니다.

---

# 생각해볼 질문

```text
1. char에서 다음 알파벳으로 어떻게 이동할 것인가?

2. 'z' 다음을 어떻게 'a'로 만들 것인가?

3. 현재 문자가 skip에 포함됐는지는 어떻게 확인할 것인가?

4. skip 문자를 만났을 때 index 카운트를 증가시켜야 하는가?

5. 변환된 문자들을 어떤 방식으로 결과 문자열에 붙일 것인가?
```

이번 건은 입력 크기도 작으니까 일단 가장 직관적인 방식으로 구현해보면 될 것 같아.
