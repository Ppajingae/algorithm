# 사칙연산

## 문제 설명

사칙연산에서 더하기(`+`)는 결합법칙이 성립하지만, 빼기(`-`)는 결합법칙이 성립하지 않습니다.

예를 들어 다음 식이 있습니다.

```text
1 - 5 - 3
```

연산 순서에 따라 결과가 달라집니다.

```text
((1 - 5) - 3) = -7

(1 - (5 - 3)) = -1
```

즉, 같은 숫자와 연산자를 사용하더라도 **괄호를 어떻게 묶느냐에 따라 결과가 달라질 수 있습니다.**

---

## 또 다른 예시

다음 식이 있습니다.

```text
1 - 3 + 5 - 8
```

가능한 연산 순서는 다음과 같습니다.

```text
(((1 - 3) + 5) - 8) = -5

((1 - (3 + 5)) - 8) = -15

(1 - ((3 + 5) - 8)) = 1

(1 - (3 + (5 - 8))) = 1

((1 - 3) + (5 - 8)) = -5
```

따라서 모든 계산 결과는:

```text
[-15, -5, -5, 1, 1]
```

이고, 이 중 최댓값은:

```text
1
```

입니다.

---

# 목표

문자열 배열 `arr`에는 숫자와 연산자 `+`, `-`가 번갈아 들어 있습니다.

가능한 모든 연산 순서 중에서 **계산 결과의 최댓값**을 구해야 합니다.

---

# 제한사항

```text
3 ≤ arr.length ≤ 201

arr.length는 항상 홀수

숫자의 개수:
2개 이상 101개 이하

연산자의 개수:
숫자의 개수 - 1

숫자:
1 이상 1,000 이하의 자연수

숫자는 문자열 형태로 저장
예: "456"

사용되는 연산자:
+
-

첫 번째 원소와 마지막 원소는 항상 숫자

숫자와 연산자는 항상 번갈아 등장
```

즉 배열의 구조는 항상:

```text
숫자 연산자 숫자 연산자 숫자 ...
```

형태입니다.

# 입출력 예 #1

```java
String[] arr = {
    "1", "-", "3", "+", "5", "-", "8"
};
```

다음과 같이 연산할 수 있습니다.

```text
1 - (3 + (5 - 8))

5 - 8
= -3

3 + (-3)
= 0

1 - 0
= 1
```

따라서 최댓값은:

```text
1
```

입니다.

---

# 입출력 예 #2

```java
String[] arr = {
    "5", "-", "3", "+", "1", "+", "2", "-", "4"
};
```

다음과 같이 연산할 수 있습니다.

```text
5 - (3 + ((1 + 2) - 4))

1 + 2
= 3

3 - 4
= -1

3 + (-1)
= 2

5 - 2
= 3
```

따라서:

```text
3
```

을 반환합니다.

# 이번 문제에서 먼저 생각해볼 것

숫자가 최대:

```text
101개
```

까지 들어올 수 있습니다.

따라서 단순히:

```text
가능한 모든 괄호 배치를 직접 만들어서 계산
```

하는 방식이 가능한지부터 생각해볼 필요가 있습니다.

예를 들어 숫자가:

```text
a b c d
```

라고 하면 전체 식을 마지막으로 계산할 때는 어떤 지점을 기준으로:

```text
(왼쪽 식) 연산자 (오른쪽 식)
```

형태로 나눌 수 있습니다.

예:

```text
1 - 3 + 5 - 8
```

을 어떤 연산자를 마지막에 계산하느냐에 따라:

```text
1  -  (3 + 5 - 8)

(1 - 3)  +  (5 - 8)

(1 - 3 + 5)  -  8
```

처럼 볼 수 있습니다.

# 주의할 점

이번 문제에서는 단순히 어떤 구간의:

```text
최댓값
```

만 알고 있으면 충분한지 생각해볼 필요가 있습니다.

특히 뺄셈:

```text
A - B
```

에서 결과를 크게 만들려면 `A`는 커야 하지만 `B`는 어떻게 되어야 할까요?

예를 들어:

```text
10 - 5  = 5
10 - -5 = 15
```

입니다.

즉 어떤 구간이 나중에:

```text
- (구간)
```

형태로 사용될 수도 있다는 점을 생각해보세요.
