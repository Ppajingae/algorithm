# 가장 가까운 같은 글자

- 플랫폼: 프로그래머스
- 난이도: Level 1
- 날짜: 2026-10-09

## 문제 설명

문자열 `s`가 주어졌을 때, 각 위치마다 자신보다 앞에 나온
같은 글자 중 가장 가까운 글자까지의 거리를 구해야 합니다.

문자열을 왼쪽부터 오른쪽으로 확인하며 다음 규칙을 적용합니다.

1. 현재 글자가 처음 등장했다면 `-1`을 저장합니다.
2. 이전에 같은 글자가 등장했다면 가장 가까운 위치까지의 거리를 저장합니다.

### 예시

문자열 `s = "banana"`인 경우:

- `b`: 처음 등장 → -1
- `a`: 처음 등장 → -1
- `n`: 처음 등장 → -1
- `a`: 2칸 앞에 같은 글자가 있음 → 2
- `n`: 2칸 앞에 같은 글자가 있음 → 2
- `a`: 2칸 앞에 같은 글자가 있음 → 2

최종 결과:

```java
int[] result = {-1, -1, -1, 2, 2, 2};
```

## 제한사항

- 1 ≤ s.length() ≤ 10,000
- 문자열 `s`는 영어 소문자로만 이루어져 있습니다.

## 기본 코드

```java
public int[] solution(String s) {
    int[] answer = new int[s.length()];

    return answer;
}
```

## 입출력 예

### 예제 1

```java
String s = "banana";

int[] expected = {-1, -1, -1, 2, 2, 2};
```

### 예제 2

```java
String s = "foobar";

int[] expected = {-1, -1, 1, -1, -1, -1};
```

## 입출력 예 설명

### 예제 1

```text
문자열: b a n a n a
인덱스: 0 1 2 3 4 5
결과:  -1 -1 -1 2 2 2
```

### 예제 2

```text
문자열: f o o b a r
인덱스: 0 1 2 3 4 5
결과:  -1 -1 1 -1 -1 -1
```

두 번째 `o`는 바로 앞에 같은 글자가 있으므로 거리는 1입니다.
