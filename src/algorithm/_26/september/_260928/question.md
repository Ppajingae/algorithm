# 전력망을 둘로 나누기

## 문제 설명

`n`개의 송전탑이 전선을 통해 하나의 **트리(Tree)** 형태로 연결되어 있습니다.

이 전선들 중 **하나를 끊어서** 현재의 전력망 네트워크를 2개로 분할하려고 합니다.

이때 두 전력망이 갖게 되는 송전탑의 개수를 최대한 비슷하게 맞추려고 합니다.

송전탑의 개수 `n`, 그리고 전선 정보 `wires`가 매개변수로 주어질 때, 전선들 중 하나를 끊어서 두 전력망의 송전탑 개수가 가능한 한 비슷하도록 나누었을 때 **두 전력망이 가지고 있는 송전탑 개수의 차이의 절댓값**을 반환하도록 `solution` 함수를 완성하세요.

---

## 제한사항

- `n`은 `2 이상 100 이하`인 자연수입니다.
- `wires`는 길이가 `n - 1`인 정수형 2차원 배열입니다.
- `wires`의 각 원소는 `[v1, v2]` 형태의 두 자연수로 이루어져 있습니다.
    - 이는 `v1`번 송전탑과 `v2`번 송전탑이 전선으로 연결되어 있다는 의미입니다.
- `1 ≤ v1 < v2 ≤ n`
- 전력망 네트워크가 하나의 **트리 형태가 아닌 경우는 입력으로 주어지지 않습니다.**

---

## 입출력 예

| n | wires | result |
|---:|---|---:|
| 9 | `[[1,3],[2,3],[3,4],[4,5],[4,6],[4,7],[7,8],[7,9]]` | 3 |
| 4 | `[[1,2],[2,3],[3,4]]` | 0 |
| 7 | `[[1,2],[2,7],[3,7],[3,4],[4,5],[6,7]]` | 1 |

---

# 입출력 예 설명

## 예제 1

```text
n = 9

wires = [
    [1,3],
    [2,3],
    [3,4],
    [4,5],
    [4,6],
    [4,7],
    [7,8],
    [7,9]
]
```

`4번`과 `7번` 송전탑을 연결하는 전선을 끊으면 두 전력망은 각각:

```text
6개
3개
```

의 송전탑을 가지게 됩니다.

따라서 두 전력망의 송전탑 개수 차이는:

```text
|6 - 3|
= 3
```

입니다.

이보다 더 비슷하게 나눌 수 없으므로 정답은:

```text
3
```

입니다.

또 다른 방법으로 `3번`과 `4번` 송전탑을 연결하는 전선을 끊어도 최선의 결과를 얻을 수 있습니다.

---

## 예제 2

```text
n = 4

wires = [
    [1,2],
    [2,3],
    [3,4]
]
```

`2번`과 `3번` 송전탑을 연결하는 전선을 끊으면:

```text
2개
2개
```

로 나누어집니다.

따라서:

```text
|2 - 2|
= 0
```

정답은:

```text
0
```

입니다.

---

## 예제 3

```text
n = 7

wires = [
    [1,2],
    [2,7],
    [3,7],
    [3,4],
    [4,5],
    [6,7]
]
```

`3번`과 `7번` 송전탑을 연결하는 전선을 끊으면 두 전력망은:

```text
4개
3개
```

의 송전탑을 가지게 됩니다.

따라서:

```text
|4 - 3|
= 1
```

정답은:

```text
1
```

입니다.

    {7, 8},
