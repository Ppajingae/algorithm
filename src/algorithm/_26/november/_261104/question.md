# 크레인 인형뽑기 게임

**난이도:** Level 1  
**날짜:** 2026-11-04  
**언어:** Java / Python

## 1. 문제 설명

N × N 크기의 정사각형 격자에 여러 종류의 인형이 쌓여 있다.

크레인은 지정된 열에서 가장 위에 있는 인형을 하나 집어 바구니로 옮긴다.

바구니에 같은 종류의 인형이 연속해서 쌓이면 해당 인형 두 개가 사라진다.

모든 크레인 작업을 마친 후 **사라진 인형의 총개수**를 반환하라.

### 게임 규칙

1. 인형은 각 열의 아래쪽부터 쌓여 있다.
2. 크레인은 지정된 열의 가장 위에 있는 인형 하나를 집는다.
3. 인형을 집으면 해당 격자 칸은 빈칸이 된다.
4. 빈 열에서 크레인을 작동하면 아무 일도 일어나지 않는다.
5. 바구니에 같은 종류의 인형 두 개가 연속해서 쌓이면 두 인형이 사라진다.
6. 바구니의 크기는 충분히 크다고 가정한다.

---

## 2. 제한사항

- `5 ≤ board.length ≤ 30`
- `board`는 N × N 정사각형 배열이다.
- `0 ≤ board[i][j] ≤ 100`
- `0`은 빈칸이다.
- `1 ~ 100`은 인형의 종류를 나타낸다.
- `1 ≤ moves.length ≤ 1,000`
- `1 ≤ moves[i] ≤ board.length`
- `moves`의 위치 번호는 1부터 시작한다.

## 3. 입출력 예시

### 입력

```text
board = [
    [0, 0, 0, 0, 0],
    [0, 0, 1, 0, 3],
    [0, 2, 5, 0, 1],
    [4, 2, 4, 4, 2],
    [3, 5, 1, 3, 1]
]

moves = [1, 5, 3, 5, 1, 2, 1, 4]
```

### 출력

```text
4
```

### 초기 격자 상태

```text
       1   2   3   4   5
     ┌───┬───┬───┬───┬───┐
  1  │ 0 │ 0 │ 0 │ 0 │ 0 │
     ├───┼───┼───┼───┼───┤
  2  │ 0 │ 0 │ 1 │ 0 │ 3 │
     ├───┼───┼───┼───┼───┤
  3  │ 0 │ 2 │ 5 │ 0 │ 1 │
     ├───┼───┼───┼───┼───┤
  4  │ 4 │ 2 │ 4 │ 4 │ 2 │
     ├───┼───┼───┼───┼───┤
  5  │ 3 │ 5 │ 1 │ 3 │ 1 │
     └───┴───┴───┴───┴───┘
```

### 크레인 작동 순서

```text
1 → 5 → 3 → 5 → 1 → 2 → 1 → 4
```

모든 작업을 마치면 사라진 인형은 총 4개이다.

## 6. 구현 목표

1. 주어진 `board`와 `moves`를 입력받는다.
2. 크레인을 지정된 위치에서 순서대로 작동시킨다.
3. 집어 올린 인형을 바구니에 담는다.
4. 같은 종류의 인형이 연속해서 쌓이면 제거한다.
5. 제거된 인형의 총개수를 반환한다.
