# 5. 다익스트라 (Dijkstra)

## 개념

```text
양수 가중치를 가진 그래프에서
한 시작점으로부터 각 노드까지의 최단거리
```

를 구한다.

---

## BFS와 차이

BFS:

```text
모든 간선 비용이 동일

A → B = 1
A → C = 1
```

다익스트라:

```text
간선 비용이 다름

A → B = 100
A → C = 3
C → B = 2
```

단순히 먼저 방문했다고 최단거리가 확정되지 않는다.

---

## 핵심

```text
현재까지 거리가 가장 짧은 노드부터 처리
```

해야 하므로:

```java
PriorityQueue<Node>
```

를 사용한다.

---

## 기본 흐름

```text
dist[] = 무한대

시작점 = 0

↓

PriorityQueue에 시작점 삽입

↓

현재 거리가 가장 짧은 노드 꺼냄

↓

현재 노드를 거쳐가는 것이 더 짧다면

dist[next] 갱신

↓

PriorityQueue에 삽입
```

---

## 떠올릴 조건

```text
그래프

+

최단거리

+

간선마다 비용이 다름

+

음수 가중치 없음
```

---

## 지금까지 연결된 문제

### 합승 택시 요금

핵심 변환:

```text
어디까지 같이 택시를 탈까?
```

를:

```text
합승 종료 지점 K
```

로 정의했다.

그러면:

```text
dist(S, K)
+
dist(K, A)
+
dist(K, B)
```

를 최소화하면 된다.

다익스트라를:

```text
S
A
B
```

에서 각각 실행해서 해결.
