# 10. 정렬 (Sorting)

정렬 자체도 중요하지만 코테에서는 다른 알고리즘을 가능하게 만드는 도구로 자주 사용된다.

예:

```text
입력 순서대로 보면 복잡함

↓

특정 기준으로 정렬

↓

앞에서부터 한 번만 순회 가능
```

---

## 단속카메라에서 배운 것

처음에는:

```text
start 기준 정렬
```

을 생각했다.

하지만 이것만으로는 판단을 확정하기 어려웠다.

그래서:

```text
어떤 기준으로 정렬해야
현재 판단을 확정할 수 있을까?
```

를 생각했다.

결과:

```text
end 기준 정렬
```

이었다.
