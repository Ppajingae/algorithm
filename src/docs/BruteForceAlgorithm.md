# 1. 완전탐색 (Brute Force)

## 개념

가능한 경우를 전부 확인하는 방식.

```text
가능한 경우 생성
→ 하나씩 전부 검사
→ 조건을 만족하는 최적값 선택
```

가장 단순하지만 경우의 수가 많아지면 사용할 수 없다.

---

## 가장 먼저 확인할 것

```text
입력 크기
```

예를 들어:

```text
N = 100

N² = 10,000
→ 충분히 가능
```

하지만:

```text
N = 100,000

N² = 10,000,000,000
→ 불가능
```

따라서:

```text
완전탐색을 해도 되는가?
```

를 판단하려면 입력 제한부터 봐야 한다.

---

## 떠올릴 조건

```text
입력이 작다.

모든 경우를 확인해도 경우의 수가 크지 않다.

다른 규칙을 찾기 어렵지만
전체 경우의 수 자체가 적다.
```

---

## 지금까지 연결된 문제

```text
전력망을 둘로 나누기

모든 전선을 하나씩 끊어본다.
```

전선은 `n-1`개뿐이므로:

```text
각 전선을 하나씩 제거
→ 두 네트워크 크기 계산
→ 차이의 최솟값
```

을 확인할 수 있었다.
