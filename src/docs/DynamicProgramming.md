# 8. DP (Dynamic Programming)

## 동적 계획법

큰 문제를 작은 문제의 결과를 이용해서 해결한다.

핵심은:

```text
같은 상태까지 오는 여러 방법이 있을 때
필요한 최적 결과만 저장한다.
```

---

## 떠올릴 조건

```text
같은 계산이 반복된다.

여러 경로가 같은 상태로 합쳐진다.

이전 결과를 이용해서
현재 결과를 계산할 수 있다.
```

---

## 가장 중요한 것

코드보다 먼저:

```text
DP 배열의 값이 무엇을 의미하는가?
```

를 정의한다.

예:

```text
dp[i][j]
=
(i,j)에 도착했을 때 얻을 수 있는 최대값
```

---

## 지금까지 연결된 문제

### 정수 삼각형

예를 들어:

```text
      7

    3   8

  8   1   0
```

가운데 `1`까지 오는 방법이 여러 개 있어도:

```text
더 작은 누적값
```

은 버릴 수 있다.

왜냐하면 그 위치 이후의 선택지는 동일하기 때문이다.

따라서:

```java
triangle[i][j] =
    triangle[i][j]
    + Math.max(
        triangle[i - 1][j - 1],
        triangle[i - 1][j]
    );
```

처럼 최적값 하나만 유지한다.
