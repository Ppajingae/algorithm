# 4. DFS vs BFS

둘 다 그래프 탐색 알고리즘이다.

차이는 **탐색 순서**다.

## DFS

```text
한 방향으로 깊게

1
↓
2
↓
4
↓
7
```

주로:

```text
재귀
Stack
```

사용.

---

## BFS

```text
가까운 것부터

        1

     2     3

   4  5   6  7
```

주로:

```text
Queue
```

사용.

---

## 선택 기준

```text
연결된 노드를 그냥 전부 방문
→ DFS/BFS 둘 다 가능할 수 있음

가중치 없는 그래프에서 최단거리
→ BFS

경로를 깊게 탐색 / 재귀적 구조
→ DFS가 자연스러운 경우가 많음
```
