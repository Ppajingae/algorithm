# 7. 분할정복 (Divide and Conquer)

## 개념

큰 문제를 여러 개의 작은 문제로 나눈다.

```text
큰 문제

↓

작은 문제
작은 문제
작은 문제
작은 문제

↓

각각 해결
```

작은 문제의 형태가 원래 문제와 동일하다.

---

## 떠올릴 조건

```text
현재 범위를 검사한다.

현재 범위만으로 해결할 수 있으면 종료한다.

해결할 수 없다면
더 작은 동일한 형태의 영역으로 나눈다.
```

---

## 지금까지 연결된 문제

### 쿼드압축 후 개수 세기

재귀 상태:

```text
(row, col, size)
```

의미:

```text
(row, col)에서 시작하는
size × size 영역을 압축한다.
```

현재 영역이 모두 같은 값이면:

```text
count++
return
```

다르면:

```text
4개의 영역으로 분할
```

한다.

```text
┌──────┬──────┐
│      │      │
│  1   │  2   │
│      │      │
├──────┼──────┤
│      │      │
│  3   │  4   │
│      │      │
└──────┴──────┘
```
