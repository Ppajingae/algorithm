# 9. Greedy

## 탐욕 알고리즘

현재 상황에서 가장 유리한 선택을 확정하고 진행한다.

하지만:

```text
지금 가장 좋아 보이는 것을 고른다.
```

만으로는 부족하다.

핵심은:

```text
이 선택을 지금 확정해도
전체 최적해를 잃지 않는가?
```

이다.

---

## 떠올릴 조건

```text
최소 / 최대 문제

정렬하면 순서대로 판단할 수 있음

현재 선택을 확정하면
이전 데이터를 다시 볼 필요가 없음

현재 최선의 선택이
미래 선택을 방해하지 않음
```

---

## 지금까지 연결된 문제

### 단속카메라

진출점 기준으로 정렬:

```java
Arrays.sort(
    routes,
    (a, b) -> Integer.compare(a[1], b[1])
);
```

가장 먼저 나가는 차량의:

```text
진출점
```

에 카메라를 설치한다.

왜냐하면:

```text
현재 차량을 확실히 잡으면서
최대한 오른쪽에 카메라를 놓아
뒤 차량과 겹칠 가능성을 최대한 남길 수 있기 때문
```

이다.

이후:

```text
camera < 현재 차량 start
```

이면 새 카메라가 반드시 필요하다.
